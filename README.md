# SENSEI ExG shield

This repository contains the hardware design files for the **SENSEI ExG shield**, a versatile biopotential sensing shield for biopotential monitoring.

## Overview

The **SENSEI ExG Shield** provides a modular and configurable approach to biopotential measurements. It supports both balanced and unbalanced supply voltage configurations through different soldering options.

![Block Diagram](Documentation/block_diagram.png)

### Key Features
- **16 biopotential channels**
- Supports both active and passive electrodes
- Configurable for fully differential and common-reference electrode setups
- Flexible supply voltage configuration (balanced and unbalanced)
- Stable MEMS-based clock (±50 ppm accuracy)
